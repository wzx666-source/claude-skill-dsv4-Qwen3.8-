# 剧本:日常作业

> **一句话**:作业里出现**图**、有要交的**关键数值**、或者你**卡住了** —— 这三个时刻读我。纯文字、没有数值要交、也没卡住,直接做题就行,别读。

本剧本是「外挂」不是「代做」:它只负责两件事 —— **看得见**(读图/手写/PDF)和**算得对**(独立复算)。做题本身在本会话里做。

---

## 什么时候读这份

| | |
|---|---|
| ✅ | 题目是照片 / 截图 / 手写稿(要转录、手写公式要转 LaTeX) |
| ✅ | 有要交的关键数值(算出来的结果要保证对) |
| ✅ | 代码作业要交,想让人挑毛病 |
| ✅ | 卡住了(同一题卡 20 分钟以上) |
| ❌ | 纯文字、没有数值要交、也没卡住 → 直接做题,别读 |

## 开口就说(不想记命令时)

| 你说 | 走到哪 |
|---|---|
| 「这道题看一下:<图片路径>」 | `qwen_vision` 转录题目 |
| 「这页手写稿转 LaTeX:<路径>」 | `qwen_vision` |
| 「复算一下这个结果:<文件>」 | `qwen_review recompute` 独立核算 |
| 「评审一下我的代码:<文件>」 | `qwen_review review` |
| 「问一下 Qwen:<问题>」 | `qwen_ask` 会诊 |

> 图片一律**存成文件再提路径**,不要粘贴 —— 粘贴的图不经过工具调用,会绕过 Qwen 视觉。

## 流程

命令头(每个终端会话复制一次即可):

```bash
S=~/.claude/skills/qwen-dual-model/scripts
```

| 步骤 | 什么时候 | 敲什么 | 为什么 |
|---|---|---|---|
| 1 | 题目是图片/照片/手写 | `node $S/qwen_vision.mjs 题目.jpg "逐行转录题目;手写公式转 LaTeX"` | 读图口径统一走 Qwen |
| 2 | 题目是 PDF | `node $S/pdf_read.mjs 题目.pdf` | 文字自动提取到同名 .txt;含图页自动走视觉 |
| 3 | 解题 | 本会话直接做 | 推理是主线的活 |
| 4 | 得出了要交的关键数值 | `node $S/qwen_review.mjs recompute 草稿.md --context "<学科+关注点>"` | 独立复算,不沿用你的中间步骤 |
| 5 | 代码作业写完 | `node $S/qwen_review.mjs review 作业.py --context "<语言/领域>"` | 换个厂商挑毛病 |
| 6 | 卡住超过 20 分钟 | `node $S/qwen_ask.mjs "我卡在……,已经试过……" --file 草稿.py` | 会诊;背景写进问题文本 |

`--context` 一句话说清领域,判据就会贴上去。例:`--context "数据结构课程作业,关注边界条件与复杂度"`。

## 最小路径(只有 3 分钟)

只做**第 1 步**(题目转录)+ **第 4 步**(复算关键数值)。这两步收益最大,其余可以先跳。

## 做完的标志

- [ ] 题目里的每个图/手写块都有过一次 `qwen_vision`(或明确说明为什么不需要)
- [ ] 要交的每个关键数值都有过一次 `recompute` 回执
- [ ] 评审报出的【高】级问题都已修复并**再送一轮**,直到没有【高】

## 本剧本不做

- **不代写作业**:解题、推导在本会话里做,本剧本只管「看得见」和「算得对」
- **不查资料**:文献检索、深度研究去 `deep-research`
- **不画图**:数据可视化去 `scipilot-figure-skill`

## 本场景的坑

1. **图片不要粘贴** → 存文件后提路径(hook 只挂在 `Read` 工具上,粘贴的图完全绕过 Qwen)
2. **`qwen_ask` 没有 `--context` 参数** → 领域背景直接写进问题文本,别写成参数
3. **`recompute` 判「无法验证」不是失败** → 它是在说"你的材料没给核算过程",把过程补上再送
4. **`qwen_vision` 的最后一个参数永远是「问题」** → 只贴图片路径不写问题,会把最后一个文件名当成问题发出去
